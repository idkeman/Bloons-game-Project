# Local development

This repository intentionally has no build dependency. A simple static server is sufficient.

For GitHub Pages, the root of the repository can be served directly.

Suggested validation:
1. Open the game.
2. Start a campaign.
3. Place at least three different towers.
4. Start and finish several waves.
5. Purchase upgrades across different paths.
6. Change targeting modes.
7. Test delete/sell/build/multi-place modes.
8. Reload and verify Continue.
9. Open /tests/test.html and verify the data integrity suite.
